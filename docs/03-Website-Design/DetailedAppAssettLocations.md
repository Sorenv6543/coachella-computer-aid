# App Folder Structure

## `src/` — Source Root

### `assets/` — Static Assets
- **`images/`** — Image files
  - `hero/` — Hero section images
  - `illustrations/` — Illustration assets
  - `icons/` — Icon assets
  - `backgrounds/` — Background images
- **`fonts/`** — Font files
- **`styles/`** — Global styles

### `components/` — Vue Components

#### `ui/` — Reusable UI Components
- `buttons/` — Button components
- `cards/` — Card components
- `chips/` — Chip components
- `forms/` — Form components
- `typography/` — Typography components
- `navigation/` — Navigation components
- `feedback/` — Feedback components (alerts, modals, etc.)
- `layout/` — Layout components (containers, grids, etc.)

#### `home/` — Home Page Sections
- `Hero/` — Hero section
- `Audience/` — Audience section
- `Services/` — Services section
- `HowItWorks/` — How it works section
- `Workshops/` — Workshops section
- `Pricing/` — Pricing section
- `Testimonials/` — Testimonials section
- `Survey/` — Survey section
- `CTA/` — Call-to-action section

#### `shared/` — Shared Components
Components used across multiple pages

### `pages/` — Page Components
- `Home.vue` — Homepage
- `Services.vue` — Services page
- `Workshops.vue` — Workshops page
- `Resources.vue` — Resources page
- `Community.vue` — Community page
- `Contact.vue` — Contact page

### `stores/` — State Management (Pinia)

### `router/` — Vue Router Configuration

### `composables/` — Reusable Composition Functions

### `plugins/` — Vue Plugins

### `types/` — TypeScript Types & Interfaces

### `utils/` — Utility Functions
