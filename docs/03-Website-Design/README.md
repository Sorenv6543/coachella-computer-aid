# Website Design — Planning & Specifications

This section contains all planning and design specifications for the Coachella Computer Aid website.

## 📄 Documents

### [Website Strategy](Website-Strategy.md)
Core philosophy and approach:
- Why we built the website the way we did
- Messaging strategy (warm, not corporate)
- Design principles and tone
- "Pay What You Can" section
- Success metrics

### [Website Roadmap](Website-Roadmap.md)
Features organized by phase:
- **Phase 1:** Foundation website (MVP)
- **Phase 2:** Workshops, community, scheduling
- **Phase 3:** Client portal, login, payment
- **Phase 4:** Volunteer portal, admin tools
- **Phase 5:** Full platform, mobile apps

### [Design Language](Design-Language.md)

- Component styles
- Responsive behavior
- Accessibility standards (WCAG AA)
