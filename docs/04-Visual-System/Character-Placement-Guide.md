# Character Placement Guide

**How and Where to Use Recurring CCA Characters**

---

## 👥 The Characters

Six recurring characters create visual continuity and help users see themselves in CCA's work. Each character represents a different demographic and learning path.

---

## 🧑 Character Profiles

### Robert — 72, Retired Teacher

**Visual:** Blue cardigan, glasses, silver hair, warm smile

**Persona:**
- Intellectually curious, used to learning
- Patient, helpful to others
- Sometimes frustrated with technology despite intelligence
- Values precision and clear explanations
- Likes to help others learn

**Where he appears:**
- Hero sections (welcoming, trustworthy)
- Services pages (teaching others)
- Workshop settings (peer mentor)
- Testimonials (success story)
- Computer help scenarios
- Learning tutorials (instructor role)

**Tone:** Patient, knowledgeable, mentoring

---

### Maria — 68, Active Community Member

**Visual:** Orange cardigan, brown hair in bun, warm expression

**Persona:**
- Socially connected, community-focused
- Wants to stay in touch with family
- Health-conscious, active lifestyle
- Values connection and relationships
- Excited to learn new things

**Where she appears:**
- Hero sections (welcoming)
- Family connection scenarios (video calls, messaging)
- Community workshop settings
- Testimonials (positive impact)
- Communication services (email, messaging)
- Social connection illustrations

**Tone:** Warm, social, enthusiastic

---

### Helen — 76, Independent & Wise

**Visual:** Sage cardigan, silver hair, glasses, observant expression

**Persona:**
- Fiercely independent, lifelong learner
- Skeptical but curious
- Values clarity and simplicity
- Prefers practical over fancy

**Where she appears:**
- Resource pages (trusted guide)
- How-it-works sections (clear steps)
- Technical explanation scenarios
- Peer support situations
- Security/safety content (protective role)
- Learning materials (teaching)

**Tone:** Clear, practical, protective

---

## 📍 Placement by Section

### Homepage Hero
- **Primary:** Robert and Maria together (welcoming couple)
- **Alternative:** Diverse group including all six characters
- **Mood:** Warm, welcoming, hopeful

### Mission Section
- **All six characters** in one illustration
- **Context:** People of different ages together
- **Mood:** Inclusive, connected, purposeful

### Audience Cards
Each card shows someone from that audience:
- **Seniors:** Robert or Maria or Helen
- **Disabilities:** David (or others in natural context)
- **Spanish-Speaking:** Maria or Carlos
- **Veterans:** Carlos
- **Low-Income:** Any character (show they're welcome)
- **Everyone:** All six together or diverse group

### Services
- **Vary the characters** across services
- **Computer Help:** Robert (teaching) or Helen (clear explanation)
- **Video Calling:** Maria with grandchildren, Carlos with family
- **Smartphone:** Any character learning, Ana teaching
- **Printer/Photos:** Maria printing memories
- **Wi-Fi/Network:** Family group including David
- **Scam Protection:** Helen protecting others
- **Password Help:** Robert remembering, Helen organizing
- **Home Visit:** All characters welcome (show in different homes)
- **Remote Support:** Any character on video call

### How It Works
- **Step 1 (Reaching Out):** Diverse characters (don't stereotype)
- **Step 2 (We Listen):** Volunteer (Ana) listening to older adult
- **Step 3 (We Help):** Pair of characters learning together
- **Step 4 (Independence):** Character confident with technology

### Workshops
- **Senior Center:** Robert, Maria, Helen in group
- **Library:** Diverse group, David included naturally
- **Community Center:** Family groups, all ages
- **Church:** Culturally appropriate gathering
- **Coffee Shop:** Casual pair learning together
- **Computer Lab:** Class setting with diverse learners
- **Home Visit:** Volunteer (Ana) with client in home
- **Remote Support:** Character on video call

### Community & Testimonials
- **Each testimonial:** Different character, different story
- **Variety:** Show Robert, Maria, Helen, Carlos, Ana, David over time
- **Authenticity:** Character in scenario relevant to their story

### Resources
- **PDF Guide Headers:** Different characters per guide type
- **Computer Basics:** Robert (experienced learner)
- **Internet Basics:** Any character learning
- **Scam Awareness:** Helen (protecting community)
- **Smartphone Guide:** Maria or Ana teaching
- **Password Security:** Helen organizing, Robert remembering

## 🎯 Variation Strategies

### Don't Always Use the Same Character
Rotate characters across sections to show:
- Anyone can learn technology
- All ages represented
- Different paths to same goal
- Inclusive community

### Use Pairs for Interaction
- **Teaching scenarios:** Ana + older character
- **Family connection:** Maria + grandchildren (illustrated), Carlos + family
- **Peer learning:** Robert + Helen together
- **Support:** Any volunteer + any learner

### Show Life Contexts
Same character in different scenarios:
- **Robert:** At home office, in library, in coffee shop, video calling
- **Maria:** With phone, with grandchildren, in workshop, at community center
- **Helen:** Teaching, organizing, mentoring, independent
- **Carlos:** Connecting with family, volunteering, community event
- **Ana:** Teaching, learning, volunteering, peer support
- **David:** Video call, workshop, at home, independent tech use

## ♿ Representation Guidelines

### David (Wheelchair User)
- **Always:** Show him independently using technology
- **Never:** Show as needy or inspirational (inspiration porn)
- **Context:** He's participating, contributing, learning
- **Natural inclusion:** Don't spotlight disability, show capability

### All Characters
- **Diverse ethnicities:** Visible across the group
- **Age ranges:** All represented (Robert 72, Maria 68, Helen 76, Carlos any age, Ana 28, David any age)
- **Ability diversity:** David naturally included in all contexts
- **Gender balance:** Mix of men and women throughout
- **Body diversity:** Show varied body types (don't standardize)

## 🎨 Character Sheet References

When generating new illustrations:

1. **Character sheets** — Reference images for each character exist
   - Location: `src/assets/images/illustrations/characters/*-character-sheet.png`
   - Used in: Generation prompts (attached as reference)
   - Updated when: Character design needs refresh

2. **Style consistency** — Same character always looks like themselves
   - Same cardigan color (Robert's blue, Maria's orange, Helen's sage, etc.)
   - Same hair style and color
   - Same relative build/posture
   - Same distinguishing features

3. **Regeneration protocol** — To refresh character illustrations
   - Attach current character sheet as reference
   - For pairs/groups, attach all involved character sheets
   - Use `--only <ids> --force` to regenerate specific slots
   - Maintains consistency while updating style/quality

See [[../../tools/illustrations/README.md|Illustration Pipeline]] for technical details.

## 📋 Placement Checklist

Before publishing an illustration with characters:

- [ ] Character(s) used are correct for the section/mood
- [ ] Character maintains visual consistency (cardigan, hair, features)
- [ ] Diversity principle applied (don't overuse same character)
- [ ] Context makes sense (character in appropriate scenario)
- [ ] Pair/group dynamics feel natural if multiple characters
- [ ] David appears naturally if showing diverse/inclusive message (not stereotyped)
- [ ] Age/ability/ethnicity representation intentional
- [ ] Accessibility considered (alt text, description clear)
