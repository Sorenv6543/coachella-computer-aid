## 🎨 Design Principles (All Sections)

✅ **Warm** — Never cold or clinical  
✅ **Friendly** — Approachable, not corporate  
✅ **Modern** — Current, not dated  
✅ **Soft** — Rounded edges, soft shadows  
✅ **Optimistic** — Hopeful, bright, encouraging  
✅ **Minimal** — Uncluttered, clean  
✅ **Accessible** — Large text, clear meaning  
✅ **Consistent** — Same colors, style, lighting everywhere
