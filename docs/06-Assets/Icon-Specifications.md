# Icon Specifications

**Custom Icon Requirements for Website & Applications**

---

## 🎨 Icon Design Principles

All custom icons follow the same visual language:

- **Consistent stroke weight** — All strokes same thickness
- **Rounded corners** — Match the soft, approachable brand
- **Flat design** — No gradients or shadows
- **Brand colors only** — Use palette from [[../../01-Project-Foundation/Brand-Bible.md|Brand Bible]]
- **Scalable** — Works at 16px, 24px, 32px, 48px, and larger
- **Meaningful** — Clear visual metaphor for what they represent
- **Accessible** — Sufficient contrast, clear at all sizes

## 🎯 Usage Guidelines

### Sizing
- **Small:** 16px (inline, labels, badges)
- **Medium:** 24px (navigation, buttons)
- **Large:** 32px (feature icons, hero sections)
- **XL:** 48px+ (large buttons, prominent features)

### Stroke Weight
- Maintain consistent stroke width across all icons
- Recommended: 2px for 24px icons, scale proportionally

### Color Usage
- **Default:** Charcoal (#343434)
- **Accent:** Warm Orange (#F4A259)
- **Secondary:** Sky Blue (#78B8D9) or Sage Green (#8BAE7B)
- **Disabled:** 50% opacity

### Accessibility
- Always pair with text label when possible
- Use `aria-label` for icon-only buttons
- Ensure sufficient contrast (4.5:1 minimum)
- Don't rely on color alone to convey meaning

## 📋 Deliverables

### Icon Set Format
- **SVG** (preferred — scalable, small file size)
- **PNG** (fallback — 32px, 64px, 128px versions)
- **Icon Font** (if using font-based icons)

### Naming Convention
Follow pattern: `icon-<category>-<name>.svg`

Examples:
- `icon-technology-laptop.svg`
- `icon-security-shield.svg`
- `icon-communication-phone.svg`
- `icon-action-close.svg`

### Export Specifications
- **Dimensions:** 24px × 24px (base size)
- **Format:** SVG with no hardcoded colors (use currentColor for dark mode flexibility)
- **Alignment:** Centered in viewBox
- **Precision:** Vector paths (no strokes converted to paths unless necessary)
