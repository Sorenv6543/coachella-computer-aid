## 🔍 Generation Workflow

When generating new batches of illustrations:

1. **Reference images** — For characters, attach the approved character sheet
2. **Style lock** — Use `STYLE-LOCK.md` for consistent prompts
3. **Batch processing** — Generate multiple candidates per item
4. **Review candidates** — Pick best representative
5. **Export** — Move picked candidates to correct folder structure
6. **Reconcile** — Run `scan.mjs` to verify all exports

See [[../../tools/illustrations/README.md|Illustration Pipeline]] for technical details.

## 🎯 Naming Convention

All illustrations follow the naming pattern:

```
<subject>-<NNN>-<slug>.png
```

Where:
- `<subject>` — What the illustration shows (character name, location, etc.)
- `<NNN>` — Zero-padded catalog ID (e.g., `001`, `042`, `300`)
- `<slug>` — Descriptive name (e.g., `laptop`, `senior-center`, `learning`)

Example: `robert-002-laptop.png`, `library-045-study-group.png`

Character sheet exception: `<subject>-character-sheet.png` (not counted in catalog)
