## 💡 Design Principles

Every decision should pass these questions:
- ✅ Is it easy to read?
- ✅ Would an 80-year-old understand it?
- ✅ Is it warm and welcoming?
- ✅ Does it reduce anxiety?
- ✅ Does it build trust?
