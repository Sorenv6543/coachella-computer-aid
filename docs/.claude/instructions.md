## 🎨 Critical Details

### Brand Voice
- ✅ Warm, patient, kind
- ✅ Plain language (no jargon)
- ✅ Reduce anxiety in every sentence
- ❌ Never corporate, cold, or technical

**Reference:** [[../01-Project-Foundation/Brand-Bible.md#brand-voice|Brand Bible — Brand Voice]]

### Visual System
- **Colors:** #FDF6EC (cream), #F4A259 (orange), #78B8D9 (blue), #8BAE7B (green), #343434 (charcoal)
- **Typography:** Large, readable, friendly
- **Style:** Warm, modern, soft, rounded corners
- **Characters:** Robert, Maria, Ana, David, Helen, Carlos (recurring cast)

**Reference:** [[../03-Website-Design/Design-Language.md|Design Language]] or [[../01-Project-Foundation/Brand-Bible.md#color-palette|Brand Bible — Colors]]

### Tech Stack
- **Frontend:** Vue 3 + TypeScript + Vite
- **Components:** Vuetify 3 (with MCP access for live docs!)
- **State:** Pinia
- **Backend:** Supabase (PostgreSQL, auth, storage)
- **Hosting:** Vercel or Netlify

**Reference:** [[../05-Technical/Tech-Stack.md|Full Tech Stack Details]]

### Accessibility Standards
- **WCAG AA minimum** everywhere
- **Large text:** 14px minimum for body, 16px default
- **Contrast:** 4.5:1 for text minimum
- **Bilingual:** English + Spanish equally supported
- **Keyboard:** Everything works without mouse

**Reference:** [[../03-Website-Design/Design-Language.md#accessibility-standards|Design Language — Accessibility]]
