# Illustration asset pipeline

One source of truth for the 300-illustration catalog, reconciled against the
files actually on disk. Replaces the old `CCA-Illustration-Library-v1.0.html`,
whose "done" state was hardcoded in three places that had already drifted apart
(the `DONE` set disagreed with the inline `done:true` flags, and neither matched
the assets in `src/`).

## Files

| File | Role | Edit by |
|------|------|---------|
| `manifest.json` | Canonical catalog: `id`, `category`, `name`, `description`, `character`, `designed`. | hand |
| `scan.mjs` | Reconciles the catalog against `src/assets/images/illustrations/`. Prints a report and regenerates the status files. | — |
| `status.generated.*` | Derived status + anomalies. **Never hand-edit** — regenerated by the scan. Git-ignored. | scan |
| `tracker.html` | Live dashboard. Reads `status.generated.js`. Opens on double-click. | — |

## Status model

Every catalog item resolves to exactly one status:

- **exported** — a real file on disk maps to this ID. This is the only "done" that counts.
- **designed** — `designed: true` in the manifest: drawn in the illustration kit or
  brand bible, but not yet exported as a standalone asset.
- **planned** — neither.

`designed` is the one human-maintained flag. `exported` is always computed from disk,
so it can't go stale.

## Naming convention

```
<character-or-subject>-<NNN>-<slug>.png      e.g. robert-001-portrait.png
```

- `NNN` is the zero-padded catalog ID and is what links a file to its manifest item.
- `*-character-sheet.png` are reference sheets — excluded from the catalog count.
- Anything without a `-NNN-` group is reported as non-conforming.

## Usage

```bash
node scan.mjs            # report + regenerate status files
node scan.mjs --dry      # report only, write nothing
node scan.mjs --assets ../../src/assets/images/illustrations   # custom root
```

Then open `tracker.html`.

## Known issues surfaced on first run

1. `carlos-007-portrait.png` should be `carlos-009-portrait.png` — Carlos's portrait
   is catalog #9. As named it collides with `helen-007-portrait.png` and leaves #9
   showing as *planned*. Fixing it clears both the collision and the mislabel.
2. `Gemini_Generated_Image_*.png` (×2) are raw un-renamed exports — rename to the
   convention or remove.

## When you scaffold the app

Add a script so the whole team can run it:

```jsonc
// package.json
"scripts": { "illos": "node tools/illustrations/scan.mjs" }
```
