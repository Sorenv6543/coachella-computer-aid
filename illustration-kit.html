Using these in your Vue build

1 · Drop the tokens into your Vuetify theme

Every illustration is built from these — so the whole site and its art stay in lockstep.

// src/plugins/vuetify.ts
theme: {
  themes: {
    ccaLight: {
      colors: {
        background: '#FBF6EC',   // cream
        surface:    '#FFFFFF',
        primary:    '#EC8A43',   // warm orange
        secondary:  '#5B93A8',   // sky-deep
        accent:     '#8FBE9A',   // sage
        'on-primary': '#FFFFFF',
        // note: use #D96E2A for orange TEXT/links to clear WCAG AA
      }
    }
  }
}

2 · Save each SVG as a file

Hit Copy SVG on any card, paste into a new file under the matching folder, and it's ready — no dependencies, fully scalable.

src/assets/images/
  hero/         hero-desert.svg
  illustrations/  character-couple.svg  character-helper.svg
                spot-scam.svg  spot-homevisit.svg  spot-pwyc.svg
  icons/        audience-*.svg  service-*.svg

3 · Recolor later, for free

Want them theme-reactive? Inline any SVG as a Vue component and swap the hex for currentColor or rgb(var(--v-theme-primary)). Because the palette is disciplined, a find-and-replace is all it takes.
